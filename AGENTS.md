# Инструкции для Codex — «Мой бюджет»

Ты — full-stack разработчик. Реализуй локальное русскоязычное веб-приложение по файлу `TECHNICAL_SPEC.md`. Если возникает противоречие, ориентируйся на ТЗ и явно фиксируй решение.

## Стек
React + TypeScript + Vite + Tailwind CSS + Recharts; Node.js + Express + Prisma + SQLite + Zod; Vitest + Playwright; Docker Compose.

## Правила
- Не ограничивайся статическим макетом: формы, API, БД и расчёты должны работать.
- Все денежные суммы храни целыми копейками, не используй float для финансовых вычислений.
- Все пользовательские тексты — на русском языке.
- Серверная валидация обязательна; изменения финансовых операций и восстановление данных — атомарные.
- По умолчанию слушай только localhost. Не подключай банки и внешнюю авторизацию в MVP.
- Не оставляй неработающих кнопок, фиктивных API и незавершённых обработчиков.
- Используй миграции БД, типизацию и тесты критических сценариев.

## Этапы
1. Проанализируй ТЗ, сформируй план, создай структуру проекта, конфигурацию и `/health`.
2. Реализуй схему Prisma, миграции, справочники счетов и категорий.
3. Реализуй операции, переводы, балансы, фильтрацию и редактирование.
4. Реализуй Dashboard, бюджеты и предупреждения.
5. Реализуй цели, взносы и аналитику.
6. Реализуй CSV/XLSX/JSON, проверку и восстановление резервных копий, настройки.
7. Добавь unit и E2E тесты, адаптивность, Docker Compose и README.

После каждого этапа запускай доступные проверки и исправляй ошибки. Не объявляй этап завершённым без проверки. В конце сообщи, что реализовано, какие тесты прошли, ограничения и команды запуска.

**Начни с этапа 1.**
